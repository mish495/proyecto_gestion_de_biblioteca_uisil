**Nota sobre el historial de Git**

Este proyecto fue desarrollado en conjunto por **Ashley Pastora** y **Francisco**.

Es posible que, al revisar el historial de Git, se observe que la mayoría de los commits aparecen únicamente a nombre de Ashley (yo). Esto no significa que Francisco no haya participado en el desarrollo del proyecto.

Durante el desarrollo ocurrió un inconveniente con el repositorio original: el proyecto se perdió de nuestros dispositivos y no fue posible recuperar el historial de Git. En el caso de Ashley, el repositorio dejó de aparecer por completo y, aunque intentamos restaurarlo utilizando las copias disponibles, no fue posible recuperar el repositorio original.

Como este problema ocurrió pocas semanas antes de la fecha de entrega, decidimos reorganizar el trabajo para poder finalizar el proyecto a tiempo. Ashley se encargó de desarrollar la mayor parte del código del sistema, mientras que Francisco colaboró principalmente en la elaboración de la documentación del proyecto en Word y apoyó en otras tareas necesarias para la entrega como main.py y crear_tablas.

Al reconstruir el repositorio y subir nuevamente el proyecto, todos los cambios quedaron registrados desde la cuenta de Ashley, por lo que el historial de Git no refleja correctamente la participación de ambos integrantes.

Por este motivo, dejamos esta aclaración para explicar que las contribuciones de cada integrante no pueden apreciarse únicamente a través del historial de Git, ya que este se vio afectado por la pérdida del repositorio original. Ambos trabajamos en conjunto para completar y entregar el proyecto.
